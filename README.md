# 📊 HR Analytics – Recruitment & Workforce Analysis

## 📌 Project Overview

This project focuses on Human Resource Analytics using Microsoft Excel to analyze recruitment data, employee demographics, workforce distribution, and hiring-related information.

The project helps understand recruitment trends, employee distribution, hiring efficiency, and workforce characteristics through data analysis and visualization.

## 🎯 Objectives

* Analyze recruitment and hiring data.
* Understand department-wise workforce distribution.
* Analyze gender diversity.
* Identify recruitment trends.
* Evaluate recruitment sources and hiring status.
* Support HR decision-making through Excel analysis.

## 🛠️ Tools Used

* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Excel Functions
* Data Visualization

## 📈 Key Analysis

* Recruitment Analysis
* Department-wise Employee Distribution
* Gender Diversity Analysis
* Employee Workforce Analysis
* Recruitment Source Analysis
* Hiring Status Analysis

## 💡 Key Learning Outcomes

* Understanding HR analytics.
* Analyzing recruitment data.
* Evaluating workforce distribution.
* Using Excel for data analysis.
* Creating meaningful HR insights.
* Supporting data-driven HR decisions.

## 🚀 Conclusion

This project demonstrates how Microsoft Excel can be used to analyze recruitment and workforce data.

It provides practical insights into recruitment trends, employee distribution, and workforce management, helping HR professionals make informed decisions.
